# processo-cnj

#### Programa emn Python que recebe números de processo no padrão CNJ (NNNNNNN-DD.AAAA.J.TR.OOOO), com ou sem pontuação, rejeitando entradas inválidas, separa as partes, identifica o segmento da Justiça e o tribunal e monta o alias do endpoint do DataJud. Também valida os dígitos verificadores.
